# نظام معالجة وقوائم الطلبة الجزائريين (DZ Student List Processor)

أداة برمجية مكتوبة بـ Python لتسهيل معالجة، تنظيم، وحساب معدلات ونسب نجاح الطلبة وفق المعايير الرسمية الجزائرية.

## المميزات:
1. استيراد ملفات Excel و CSV.
2. الحساب الآلي للمعدلات (CC, TD, Exam).
3. استخراج التقرير الإحصائي الشامل ونسبة النجاح والمتوسط العام.
4. تصدير التقارير بملفات إكسيل جديدة.

## التثبيت والتشغيل:
```bash
pip install -r requirements.txt
python main.py
